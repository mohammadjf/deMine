# **App Name**: DeMine

## Core Features:

- Interactive Grid: Generate a grid of cells that can be revealed by the user. Grid sizes include beginner, intermediate and expert.
- Mine Placement: Randomly place mines on the grid. THe number of mines should vary with the difficulty selected. Ensure no mine is placed on the first click.
- Cell Revealing: Reveal cells upon user click. If a mine is revealed, the game ends. Display number of adjacent mines if no mine is revealed.
- Flagging: Allow users to flag potential mines to avoid clicking them.
- Win/Loss State: Determine if the game is won (all non-mine cells revealed) or lost (a mine is clicked). Clearly indicate the result.
- Restart Button: Provide a button to restart the game with a new mine configuration. Allow restart during game play or after a win/loss.

## Style Guidelines:

- Primary color: Dark green (#344D39) to provide a sophisticated, natural feel, reminiscent of classic designs.
- Background color: A desaturated, darker green (#2A332C) unifies the background.
- Accent color: Gray (#808080) analogous to the dark green for interactive elements to achieve clear visibility without a loud aesthetic.
- Body and headline font: 'Inter' sans-serif to ensure modern UI readability.
- Use simple, clear icons for mines and flags. Outlined for better visibility against the dark background.
- Grid layout with clearly defined cells. Ensure spacing is consistent and balanced.
- Subtle reveal animation upon cell click. Brief highlight on flagged cells when game is lost to show mines.
